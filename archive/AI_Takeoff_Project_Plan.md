# AI Takeoff 2026–2045: Project Plan

## Phase 1 — Define the Fields and Gather Sources

- [ ] List all fields to cover (you'll feed these in)
- [ ] For each field, identify the **top open research questions** (the ones that, once solved, unlock downstream capabilities)
- [ ] Tag each question with your source material (papers, roadmaps, expert forecasts, prediction markets, etc.)
- [ ] Flag any fields where source coverage is thin — decide whether to cut or supplement

**Output:** A master table — one row per research question, columns for: field, question, source(s), current status, estimated difficulty.

---

## Phase 2 — Assign Projected Solution Dates

- [ ] For each research question, assign a projected year of solution (or range)
- [ ] Document the reasoning/evidence behind each date (existing trendlines, expert consensus, compute scaling curves, funding trajectories, etc.)
- [ ] Identify **high-uncertainty questions** where the date could swing 5+ years either way
- [ ] Decide on scenario framing: single median timeline, or multiple scenarios (conservative / base / aggressive)?

**Output:** The master table now has projected dates and confidence levels.

---

## Phase 3 — Build the Dependency Graph (Tech Tree)

- [ ] Identify which breakthroughs are **prerequisites** for others (e.g., "reliable long-horizon planning" before "autonomous scientific research")
- [ ] Map cross-field dependencies (e.g., novel materials ← AI-driven materials science ← foundation model capabilities)
- [ ] Identify **critical path nodes** — the bottlenecks whose delay cascades everything downstream
- [ ] Identify **parallel tracks** that advance independently but converge at key points
- [ ] Validate that the projected dates respect dependency ordering (a prerequisite can't be solved after the thing it unlocks)
- [ ] Design the visual representation — node/edge graph with time on the x-axis, fields on the y-axis

**Output:** A tech tree diagram (or structured data that can be rendered as one) with dated nodes and dependency edges.

---

## Phase 4 — Narrative and Analysis

- [ ] Write the "what happens when" narrative — walk through the timeline chronologically
- [ ] Identify **inflection points** — years where multiple breakthroughs converge and the rate of change accelerates
- [ ] Analyze economic/market implications at each stage (this is your investor audience)
- [ ] Call out the **biggest uncertainties** and what would change the timeline most
- [ ] Add a section on risks, governance gaps, and what could go wrong

**Output:** The analytical backbone of the report — 15–30 pages of structured narrative.

---

## Phase 5 — Assemble the PDF Report (Paid Product)

- [ ] Structure the report:
  - Executive summary (1–2 pages)
  - Methodology and sources
  - The tech tree (full visual + field-by-field breakdown)
  - Chronological walkthrough (2026–2030, 2030–2035, 2035–2040, 2040–2045)
  - Investment/market implications
  - Key uncertainties and scenario variants
  - Appendix: full source table, methodology notes
- [ ] Design charts and visuals (tech tree, timeline graphics, confidence intervals)
- [ ] Review, fact-check, and tighten
- [ ] Set up distribution (Gumroad, Stripe, Substack paywall, etc.)

**Output:** Final PDF report, priced and available for purchase.

---

## Phase 6 — Create the Free Content Layer

### Blog Post
- [ ] Distill the report into a 1,500–2,500 word blog post
- [ ] Focus on 3–5 most surprising or high-impact findings
- [ ] Include 1–2 visuals from the report (teaser quality)
- [ ] End with a clear CTA linking to the full report
- [ ] Publish on Substack / personal site / Medium

### Twitter/X Thread
- [ ] Condense into a 10–15 tweet thread
- [ ] Lead with the single most compelling finding
- [ ] Use one visual (the tech tree or a simplified timeline)
- [ ] Final tweet = CTA to the blog post and report
- [ ] Draft alt-text for any images

**Output:** Blog post draft + Twitter thread draft, both linking to the paid report.

---

## Checklist: Decisions to Make Before Starting

1. **How many fields?** (Scope control — more fields = more work but broader appeal)
2. **Single timeline or multiple scenarios?** (One "most likely" path, or conservative/base/aggressive?)
3. **How granular?** (Year-level resolution? Or broader era buckets like "early 2030s"?)
4. **What's the price point for the report?** (Affects positioning — $29 impulse buy vs. $199 research product)
5. **Where will you publish the blog?** (Substack, personal site, etc.)
6. **Do you want peer review / feedback rounds before publishing?**

# Technology Atlas

A map of the breakthroughs worth working towards, and of the milestones that show how close each one is. It is a map, not a forecast: it makes no claims about order or dates. Each breakthrough has a completion test set, where possible, by an outside body (a regulator, a prize, a standards body), milestones on the way, and published results judged against them, each with a quotation checked against its source.
